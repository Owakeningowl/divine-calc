# Divine Sword & Blessed Shield Damage Calculator

A damage calculator with Divine Sword & Blessed Shield's stats, abilities and all 404 trainer teams in story order.

Live at <https://owakeningowl.github.io/divine-calc/>.

**Load Switch save** reads a Sword or Shield save file in your browser and puts your party and boxes into Team / Box. The file is never uploaded.

Built on the official [@smogon/calc](https://github.com/smogon/damage-calc) engine by Honko, Austin and Kris, with the interface from Joggel's calc. The save format follows [PKHeX](https://github.com/kwsch/PKHeX). Divine Sword & Blessed Shield is by its own authors; this is an unofficial tool.
